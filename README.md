# gadgets-tools

Tools and firmware for various Flipper Zero / ESP32 gadgets — one folder per device.

| Folder | Device | What's here |
| --- | --- | --- |
| [`flipper-feberis/`](flipper-feberis/) | Flipper Zero + Feberis Pro | ESP32 recon firmware (WiFi scan + GPS + offline dashboard, WiGLE/GPX export) and the `geotag` tool |
| [`t-dongle-s3/`](t-dongle-s3/) | LilyGo T-Dongle-S3 | USBArmyKnife (USB pentest implant) + payload library |
| [`m5stickc-plus2/`](m5stickc-plus2/) | M5StickC PLUS2 | Bruce (Flipper-like ESP32 multi-tool) |
| [`galaxy-s10-nethunter/`](galaxy-s10-nethunter/) | Samsung Galaxy S10 (SM-G973F) | Kali NetHunter reinstall playbook + `verify.sh` |
| [`flipper-wifi-devboard/`](flipper-wifi-devboard/) | Flipper Zero + official WiFi Dev Board | not started yet |

Each folder is self-contained — see its own README.
